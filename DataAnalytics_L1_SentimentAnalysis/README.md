# Task 4: Sentiment Analysis

## 📌 Project Overview
This task involves building a Natural Language Processing (NLP) pipeline to analyze textual data (product reviews or social media feedback) and classify sentiments into Positive, Neutral, or Negative classes.

## 🛠️ Technologies & Tools Used
* **Python**
* **NLTK / TextBlob** (Natural Language Toolkit)
* **Pandas & NumPy**
* **Matplotlib & WordCloud** (Visualizing key terms)

## 🔍 Workflow Pipeline
1. **Text Preprocessing:** Lowercasing, removing special characters/punctuation, stop-word removal, and tokenization.
2. **Sentiment Scoring:** Calculated sentiment polarity and subjectivity metrics for each text sample.
3. **Visualization:** 
   * Bar plots showing sentiment score distributions.
   * WordClouds highlighting prominent keywords in positive and negative reviews.

## 💡 Key Findings
* Over **65%** of user responses expressed positive sentiment.
* Negative sentiment primarily related to shipping delays and customer service resolution times.
